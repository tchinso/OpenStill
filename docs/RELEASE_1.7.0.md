# OpenStill 1.7.0 점검 기록

## 로컬 백업

- 같은 원본 ID를 가진 복구 항목의 실제 내용이 다르면 각각 보관합니다. 동일 원본을 다시 가져올 때는 기존 항목을 재사용합니다.
- 저장된 변경 이력과 검증 가능한 복구 스냅샷을 v5 백업에 포함합니다. 삭제 원본의 레코드와 지문을 보존해 정상 원본과 손상 원본을 구분합니다.
- 이전 v2·v3·v4 백업과 원문 생략 표시가 있는 v5 백업의 읽기를 유지합니다.

## Koofr 백업

- 사용자가 연결한 Koofr에 v5 JSON을 저장하고 기기별 완료 백업을 선택해 복원합니다. 자동 백업과 보관 정리는 기본값에서 꺼져 있습니다.
- WebDAV는 offscreen 문서에서 실행합니다. 전용 Worker가 v5 part를 직렬화하고, 서비스 워커는 확인된 part와 다음 실행 위치를 로컬에 기록합니다. 전체 part를 확인한 뒤 완료 목록을 게시합니다.
- 앱 비밀번호, 이 기기의 백업 설정과 작업 상태는 이식 가능한 백업 설정과 별도로 보관합니다.

## 검증

2026-11-09 기준, 설치된 Edge와 임시 프로필을 포함한 전체 회귀에서 203개가 통과했고 실패는 0개였습니다. 실제 사용자 백업을 지정하는 선택 검사 1개는 건너뛰었습니다.

- 실제 확장과 합성 WebDAV에서 대시보드를 닫고 서비스 워커를 종료하는 동안 30 MiB 이상 part의 41초 PUT이 이어졌습니다. 새 서비스 워커에서 자동 백업의 완료를 확인했고, 원격 백업 선택 복원과 반복 복원도 통과했습니다.
- 합성 WebDAV의 인증·일시 오류·용량 제한·리다이렉트·손상 목록·part 검증·완료본 보관 경계를 검사했습니다.
- 동일 ID의 서로 다른 원본, 동시 보관, File 바이트 왕복, 이력 보존, 폐기 자료의 스냅샷 재복원, 정상·손상 삭제 원본을 검사했습니다.

배포 ZIP의 manifest 버전이 1.7.0이고 신규 백업 모듈과 런타임 진입점 10개가 소스와 바이트 단위로 일치함을 확인했습니다.

### 실제 Koofr

2026-11-09에 사용자가 임시 Edge 프로필에 입력한 시험용 앱 비밀번호로 Koofr WebDAV에 연결했습니다. 시험용 확장은 기본 백업 경로 대신 이 실행만을 위한 별도 폴더를 사용했습니다.

- 연결 확인용 JSON의 생성·읽기·삭제를 확인했습니다.
- 한글·이모지·HTML 스냅샷을 포함한 v5 JSON part 2개와 완료 목록을 저장하고 읽어 검증했습니다.
- 합성 추적을 삭제한 뒤 원격 백업으로 복원해 스냅샷을 비교했습니다. 반복 복원은 중복 추적이나 복구 원본을 만들지 않았습니다.
- 격리된 원격 시험 폴더와 로컬 임시 프로필을 정리했습니다.

계정 플랜별 호환 범위와 실제 서버에서 회선을 강제로 끊은 뒤의 재개는 별도 검증 항목입니다. 41초 업로드와 서비스 워커 재시작은 합성 WebDAV에서 확인했습니다.
