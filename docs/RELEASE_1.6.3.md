# OpenStill 1.6.3 점검 기록

실제 사용 백업과 코드의 경계 상황을 점검해 재현된 문제를 수정한 안정성 업데이트입니다. 저장 형식과 권한은 기존과 같습니다.

## 수정 사항

| 경로 | 재현 조건 | 수정 후 동작 |
| --- | --- | --- |
| 스냅샷 읽기 | 내용을 읽는 동안 같은 추적을 삭제하거나 라벨을 변경 | 읽기 완료 시 최신 레코드를 다시 확인해 삭제·수정된 상태를 유지 |
| 실시간 감시 | 내용은 같지만 일부 선택 영역이 사라지거나 복구 | 선택 상태도 중복 판정에 포함해 확인 필요 상태를 표시하거나 해제 |
| 실시간·예약 확인 병행 | 예약 확인이 실패하거나 다른 내용으로 기준값을 갱신한 뒤 이전 실시간 내용이 다시 관측됨 | 실시간 캐시를 초기화해 오류 회복과 최신 기준값 대비 변경을 처리 |
| 선택자 변환 | 제목 속성이 있는 요소를 XPath/XCSS로 변환하거나 Shadow DOM으로 선택 범위가 확대됨 | 초기 선택과 같은 속성 필터를 적용하고 동일한 요소 집합일 때만 변환 |
| XCSS 해석 | ID 마지막 문자가 이스케이프된 `+`, `>`, `~`이고 뒤에 하위 선택자가 있음 | ID 문자와 CSS 결합자를 구분해 선택기와 실제 캡처에서 동일하게 처리 |
| 일정 편집 | 잘못된 숫자 입력 후 수동 등 다른 확인 방식으로 전환 | 숨겨진 입력란은 검증에서 제외하고 현재 방식만 검증 |
| 대시보드 로딩 | 초기 추적 수와 로딩 세션의 실제 항목 수가 다름 | 세션 항목 수를 사용하고 마지막 페이지 응답에서 종료 |
| 가져오기 재개 | 레코드 저장 직후 서비스 워커 종료, 또는 재개와 상태 조회가 겹침 | 저장된 인덱스에서 이어 쓸 위치를 복구하고 최신 세션을 유지해 앞선 레코드를 보존 |
| 손상 백업 복구 | 원문 파일 조각의 Base64가 손상됨 | 해당 원본을 복구함에 보존하고 뒤의 정상 레코드를 계속 처리 |

## 실제 데이터 검증

사용자가 제공한 약 30.6 MB 백업을 외부 사이트에 접속하지 않고 검사했습니다. 원본 파일과 개인 데이터는 저장소에 추가하지 않았습니다.

- v5 봉투 645개 레코드: 추적 155개, 스냅샷 332개, 복구 원본 157개, 설정 1개.
- 스트리밍 해석, 레코드 체크섬, 백업 세트 완전성 검사 통과.
- 추적 155개 가져오기 후 내보내기·재가져오기 통과, 복구 대기 0개.
- 이름·URL·라벨·선택자·추적 설정·일정·스냅샷·변경 이력·실행 기록·읽음 상태를 SHA-256으로 비교해 일치 확인.
- 같은 추적을 다시 가져오면 추가 등록 0개, 중복 155개로 처리.
- 스냅샷 332개의 대시보드 내용·비교 렌더링에서 페이지 오류 0건.

실제 로그인 사이트의 새 페이지 캡처는 이 검사에 포함하지 않습니다. 선택·캡처 동작은 로컬 합성 페이지와 브라우저 회귀 테스트로 확인합니다.

## 검증 실행

2026-10-18 검증 결과:

- 전체 Node·브라우저 테스트: 186개 통과, 별도 실행하는 실제 백업 테스트 1개 건너뜀.
- 마지막 가져오기 동시 실행 수정 후 영향 범위 재검증: 실제 백업 테스트와 추가 회귀 테스트를 포함한 45개 모두 통과. 중복을 제외한 전체 검증 항목 188개 통과.
- Edge 임시 프로필에 실제 확장을 로드해 대시보드·런타임 메시지·백업 복원을 확인했습니다.
- JavaScript 구문 검사와 `git diff --check` 통과. 배포 ZIP의 1.6.3 버전과 변경된 소스 파일 일치 여부를 확인했습니다.

Node.js 기본 테스트:

```powershell
node --test tests/*.test.js
```

Playwright가 설치된 환경에서는 모듈 경로를 지정해 브라우저 테스트를 포함할 수 있습니다. 필요하면 `OPENSTILL_CHROMIUM_EXECUTABLE`로 Chromium 계열 브라우저 실행 파일을 지정합니다.

```powershell
$env:OPENSTILL_PLAYWRIGHT_MODULE = 'C:\path\to\node_modules\playwright'
$env:OPENSTILL_EXTENSION_SMOKE = '1'
node --test --test-concurrency=2 tests/*.test.js
```

실제 백업을 별도로 재검증하려면 아래의 선택 테스트를 사용합니다. 백업 내용은 테스트 출력에 표시하지 않습니다.

```powershell
$env:OPENSTILL_SAMPLE_BACKUP = 'C:\path\to\openstill-export-part-001.json'
node --test --test-name-pattern='optional local backup' tests/service-worker-import.test.js
```

전체 브라우저 테스트의 실제 확장 로드 검사는 실행 환경이 확장 로드를 허용하는 브라우저를 필요로 합니다. 테스트 결과의 건너뜀 여부를 확인해야 합니다.
