# OpenStill

OpenStill은 사용자가 CSS 선택자로 고른 웹페이지 요소의 텍스트가 바뀌었는지 주기적으로 확인하는 Manifest V3 Chrome 확장 프로그램입니다. 저장·비교·내보내기는 모두 브라우저 로컬에서 이루어집니다.

## 포함된 기능

- 한 주소에 최대 20개 CSS 선택자를 **하나의 추적**으로 저장하고, 선택 결과 전체를 DOM 순서의 단일 목록 스냅샷으로 비교
- 새 글이 목록 앞에 추가되어 기존 글의 위치가 밀려도, 같은 항목은 유지하고 새 항목·목록에서 빠진 항목만 한 주소의 변경 내용으로 표시
- 관리 화면에서 같은 사이트를 하나로 묶고, 그 아래에 주소별 추적과 선택자 목록을 표시
- 페이지 단위 **주소만 변경**·**주소만 복제**로 CSS 선택자, 이름, 라벨, 간격을 유지한 채 다른 게시판·검색 결과를 빠르게 추적

- 현재 탭에서 여러 요소를 가리키고 클릭하는 시각적 CSS 선택기
- 짧고 안정적인 후보를 우선 탐색하는 CSS 선택자 생성, 직접 수정, 실시간 일치 개수·텍스트 미리보기
- 1시간부터 14일까지, 1시간 단위의 검사 간격 (`2일 18시간` 등)
- 실제 텍스트 변경 시 시스템 알림과 자체 생성한 짧은 두 음의 알림음
- 모든 선택 결과가 비었을 때만 변경 알림 대신 `확인 필요` 상태로 표시하고, 마지막 정상 기준값을 보존
- 줄 단위·단어 단위 diff로 새로 추가된 항목과 수정된 텍스트를 강조 표시
- 여러 라벨 부착 및 라벨별 필터링
- 작은 Chrome 팝업 창으로 해당 페이지 열기
- URL, CSS 선택자, 저장 텍스트, 라벨, 마지막 확인/변경 시각을 담은 JSON 내보내기·불러오기

## 로컬에서 설치하기

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 우측 상단의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 저장소의 루트 폴더를 선택합니다.
4. 추적할 HTTP/HTTPS 페이지를 열고 Chrome 툴바의 OpenStill 아이콘을 누릅니다.
5. **이 페이지에서 요소 선택**을 누르고 원하는 요소를 여러 개 클릭합니다. **요소 추가**로 계속 고르고, 이름·라벨·간격을 정한 뒤 한 번에 저장합니다.

요소 선택을 시작할 때 OpenStill은 그 사이트 한 곳에 대해서만 접근 권한을 요청합니다. 설치 시 모든 사이트에 대한 읽기 권한을 요청하지 않으며, 선택기를 저장하지 않고 닫으면 새로 받은 권한도 정리합니다.

## 권한

| 권한 | 사용하는 이유 |
| --- | --- |
| `activeTab` | 사용자가 툴바에서 선택기를 연 현재 탭에서만 요소를 고릅니다. |
| `scripting` | 사용자가 시작한 선택기만 현재 페이지에 주입합니다. |
| `storage` | 모니터, 텍스트 기준값, 라벨, 설정을 로컬에 저장합니다. |
| `alarms` | 가장 가까운 검사 시각에 맞춰 확인을 예약합니다. |
| `notifications` | 실제 텍스트 변화가 생겼을 때 시스템 알림을 보냅니다. |
| `offscreen` | CSS 선택자 문법 검증 및 알림음 | 서비스 워커에서 지원하지 않는 DOM 문법 검증과 로컬 Web Audio 알림음을 처리합니다. |
| 선택적 HTTP/HTTPS 사이트 권한 | 사용자가 저장하는 정확한 사이트를 임시 백그라운드 탭에서 렌더링해 정기 확인합니다. |

`tabs`, `cookies`, `webRequest`, `downloads`, `unlimitedStorage`, 전체 사이트의 상시 호스트 권한은 요청하지 않습니다.

## 동작과 한계

- 정기 확인 때는 사용자가 허용한 사이트를 비활성 임시 Chrome 탭에서 렌더링하고, DOM이 잠시 안정된 뒤 CSS 선택자를 적용한 다음 탭을 닫습니다. 따라서 JavaScript로 그려지는 일반 페이지도 확인할 수 있습니다. 이 페이지 로드는 Chrome의 평소 세션 상태에 따라 달라질 수 있지만, OpenStill은 쿠키 값을 읽거나 외부로 전송하지 않습니다.
- 한 CSS 선택자는 하나 이상의 요소와 일치할 수 있으며, 여러 선택자의 결과는 중복 없이 DOM 순서대로 합쳐 비교합니다.
- 모든 선택자가 아예 일치하지 않으면 로그인 상태, 페이지 구성 또는 CSS 선택자를 확인할 수 있도록 `확인 필요`로 표시하고 마지막 정상 기준값을 보존합니다. 일부 선택자만 일치해도 남은 결과를 포함한 전체 목록 비교는 계속합니다.
- 닫힌 Shadow DOM과 cross-origin iframe 내부는 표준 CSS 선택자로 추적할 수 없습니다.
- Chrome 알람은 절전·브라우저 종료 중 정확한 시각에 실행되지 않을 수 있습니다. 다시 활성화되면 가능한 한 빨리 확인하고 다음 간격을 다시 계산합니다.
- "작은 창"은 Chrome의 `popup` 창입니다. 탭·주소창 UI는 줄어들지만 운영체제 제목 표시줄까지 제거할 수는 없습니다.
- 페이지 텍스트는 현재 값과 마지막 변경 전 값을 각각 최대 10,000자로 저장합니다. 전체 HTML이나 무제한 변경 이력은 보관하지 않습니다.

- 개인정보 보호를 위해 시크릿 창에서는 OpenStill을 사용할 수 없습니다.

## 가져오기와 내보내기

관리 화면의 **내보내기**는 `openstill-export` v2 형식의 JSON을 다운로드합니다. 이 파일에는 주소 단위 모니터의 URL, 페이지 제목, CSS 선택자 목록, 현재/이전 목록 기준값, 라벨, 간격, 활성 상태, 마지막 확인/변경 시각과 알림 설정이 들어 있습니다.

**불러오기**는 같은 형식(v2)만 받고 기존 목록과 안전하게 병합합니다. 한 번에 최대 100개 주소 추적과 8 MB JSON 파일을 받습니다. 새 사이트 권한은 불러오기 과정에서 자동으로 요청하지 않습니다. 권한이 없는 활성 항목은 일시정지·`권한 필요` 상태로 들어오며, 목록의 **권한 허용 및 시작** 버튼을 눌러 각 사이트별로 시작할 수 있습니다.

## Chrome Web Store 준비

- [PRIVACY.md](PRIVACY.md)의 개인정보처리방침을 공개 URL로 게시하고 Store listing의 Privacy practices를 실제 동작과 동일하게 작성합니다.
- 업로드 ZIP에는 확장 프로그램 파일만 포함하세요. 개발 참고용 `References/` 폴더는 패키지에 넣지 않습니다.
- 모든 JavaScript·CSS·아이콘·소리는 이 저장소에 포함된 독자적인 파일입니다. CDN, 원격 코드, 참고 앱의 소스·아이콘·오디오는 사용하지 않습니다.
- 권한 변경 시 [STORE_SUBMISSION.md](STORE_SUBMISSION.md)의 권한 사유도 함께 갱신하세요.

배포 ZIP은 PowerShell에서 `./package-release.ps1`를 실행해 만들 수 있습니다. 이 스크립트는 필요한 확장 프로그램 파일만 명시적으로 복사하므로 `References/`를 포함하지 않습니다.
